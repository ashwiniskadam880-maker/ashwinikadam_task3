# 🏧 ATM Interface System

A simple Java console-based ATM application that simulates basic banking operations. Users can securely log in using a PIN and perform transactions such as checking balance, depositing money, withdrawing funds, and transferring money.

## ✨ Features

* PIN-based login authentication
* Check account balance
* Deposit money
* Withdraw money
* Transfer money to another account
* Transaction history tracking
* Menu-driven console interface

## 🛠️ Technologies Used

* Java
* ArrayList
* Scanner
* Object-Oriented Programming (OOP)

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone <https://github.com/ashwiniskadam880-maker/ashwinikadam_task3.git>
   ```

2. Compile the program:

   ```bash
   javac ATMinterface.java
   ```

3. Run the application:

   ```bash
   java ATMinterface
   ```
